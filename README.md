# 🧮 JavaFX Calculator

A simple and clean **desktop calculator application** built using **Java and JavaFX**.  
This is my **first project**, created to practice core programming concepts and JavaFX UI development.

---

## ✨ Features

- Basic arithmetic operations  
  - Addition (+)  
  - Subtraction (−)  
  - Multiplication (×)  
  - Division (÷)
- Clear (C) and All Clear (AC)
- Backspace (remove last digit)
- Decimal number support
- Prevents invalid inputs (like leading zeros)
- Clean and modern UI using JavaFX CSS
- Smooth button hover effects

---

## 🛠 Technologies Used

- **Java**
- **JavaFX**
- **FXML**
- **CSS**
